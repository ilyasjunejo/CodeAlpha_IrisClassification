# Iris Flower Classification 🌸

## Overview
Machine Learning classification model to predict iris flower species using Python & Scikit-learn.

## Dataset
- 150 samples
- 4 features (sepal & petal measurements)
- 3 classes (Setosa, Versicolor, Virginica)

## Model Performance
- **Algorithm:** Random Forest
- **Accuracy:** 100%
- **Precision:** 1.0
- **Recall:** 1.0
- **F1-Score:** 1.0

## Files
- `iris_classification.py` - Main code
- `iris_distributions.png` - Feature distributions
- `iris_correlation.png` - Correlation heatmap
- `iris_confusion_matrix.png` - Model confusion matrix
- `iris_model_comparison.png` - Model comparison
- `requirements.txt` - Dependencies

## How to Run
```bash
pip install -r requirements.txt
python iris_classification.py
```

## Technologies Used
- Python 3.8+
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Results
✅ Perfect classification on test data (100% accuracy!)
✅ Random Forest outperformed other algorithms
✅ No overfitting observed
✅ Production-ready model

## Key Insights
- Setosa is easily distinguishable
- Petal measurements are strong predictors
